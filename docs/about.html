ABOUT

How our post office works

webserv is an HTTP/1.1 server written in C++98 for the 42 Common Core. One clerk at the front desk, a single poll() loop, watches every visitor at once: no threads, and nobody waits in line.

THE ROOMS AND THE CODE BEHIND THEM
ROOM 02 + 07

Front desk & Mail carrier

Core Engine

Sockets, the poll() event loop, accepting visitors, reading requests and sending replies without ever blocking.

ROOM 03 + 05 + 06

Opening room, Workshop & Stamping desk

Protocol & CGI

Reads the HTTP request, runs CGI scripts, and builds the reply with the right status code.

ROOM 04

Sorting room

Config & Infra

Reads the config file: ports, routes, allowed methods, size limits and error pages. It decides where every letter goes.

What our post office can do

  • Methods GET, POST and DELETE
  • One poll() for every socket and every CGI pipe
  • Static files, uploads, directory listing, redirects and custom error pages
  • CGI scripts in Python, with a timeout for slow scripts
  • Ports, routes, methods and size limits from an NGINX-style config file
