CGI · /cgi-bin/

The workshop

Here the letter is not copied from a shelf: a Python script writes the reply. The server runs it with fork() + execve() and sends back what the script prints.

GET · QUERY STRING

A note on the envelope

Your text goes into the address, after the ?. The script reads it from QUERY_STRING.

POST · BODY

A letter inside the envelope

Your text goes in the body. The script reads it from stdin.

TIMEOUT · SLOW SCRIPT

A very slow worker

slow.py sleeps 10 seconds. While it works, open another page: the post office must stay open for other visitors.

The script's reply appears here.
