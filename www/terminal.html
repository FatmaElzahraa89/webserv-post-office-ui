FROM THE TERMINAL

Letters a browser won't send

A browser cleans every request before sending it, so it can't test the broken ones. Here are the commands for the terminal: press Copy, paste in the terminal (Ctrl+Shift+V) and press Enter. Each one shows the answer to expect and what it checks. Open sends the same request from the browser, when a browser can; Page shows the error page the answer uses.

Before you start: make then ./webserv default.conf in a first terminal, and paste the commands in a second one.
